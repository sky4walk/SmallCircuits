Bedienung


    

  • ▶ Start (F5) übersetzt, prüft und startet das Programm; Schritt (F10) führt genau eine Anweisung aus (egal in welchem Task), ❚❚ hält an, ■ setzt zurück. Übersetzen (Strg+B) prüft nur.
    • 

  • Tempo: „maximal“ rechnet so schnell es geht; „Trace“ hebt jede Anweisung im Quelltext hervor und aktualisiert alle Ansichten. Geänderte Variablen werden markiert.
    • 

  • Haltepunkte: auf eine Zeilennummer klicken.
    • 

  • Zeitscheibe: Anzahl Anweisungen, die ein Task ausführt, bevor der simulierte Scheduler zum nächsten rechenbereiten Task wechselt. Der Ablauf ist bei gleicher Eingabe und gleicher Einstellung immer identisch.
    • 

  • Reiter: mehrere Dateien (z. B. stapel.ads, stapel.adb, main.adb). Die Reihenfolge der Reiter ist die Übersetzungsreihenfolge – Spezifikationen zuerst. Doppelklick benennt um, + legt eine Datei an. Eine Datei darf auch mehrere Übersetzungseinheiten enthalten (wie bei gnatchop).
    • 

  • Das Hauptprogramm ist die letzte parameterlose Bibliotheksprozedur.
    • 

  • Eingabe: Wartet das Programm in Get/Get_Line, leuchtet die Eingabezeile auf. Man darf auch vorab tippen. EOF beendet die Eingabe (End_Of_File wird wahr, weiteres Lesen löst End_Error aus).
    • 

  • Laden liest .adb/.ads-Dateien (mehrere auf einmal möglich), Speichern lädt den aktuellen Reiter herunter. Die Seite speichert nichts im Browser.
    • 




Unterstützte Teilmenge


Typen

    

  • Ganzzahltypen range a .. b (Integer = 32 Bit, Long_Integer = 53 Bit), modulare Typen mod n (Ada 95)
    • 

  • Gleitkomma digits n (intern immer 64 Bit; digits bestimmt Ausgabe und 'Digits), Festkomma delta d range a .. b, Duration
    • 

  • Aufzählungstypen inkl. Zeichenliterale, Boolean, Character (Latin-1), String
    • 

  • Untertypen, abgeleitete Typen (type Meter is new Float) – starke Typisierung ohne implizite Umwandlung
    • 

  • Felder: beliebige diskrete Indextypen, mehrdimensional, uneingeschränkt (range <>), Ausschnitte, Aggregate (positionell, benannt, others)
    • 

  • Records mit Vorgabewerten, Diskriminanten und Varianten (veränderliche Records bei Diskriminanten mit Vorgabe)
    • 

  • access-Typen, unvollständige Typen, Allokatoren new T / new T'(…), Ada.Unchecked_Deallocation
    • 

  • private und limited private Typen, aufgeschobene Konstanten
    • 

  • Ausbaustufe Ada 95: tagged-Typen, Erweiterung, abstrakte Typen/Operationen, klassenweite Typen T'Class, dynamisches Dispatching
    • 



Anweisungen und Unterprogramme

    

  • Zuweisung, if/elsif/else, case (Vollständigkeit und Eindeutigkeit werden geprüft), loop, while, for (auch reverse, über Untertypen und 'Range), exit [Name] [when], benannte Schleifen und Blöcke, declare-Blöcke, return, null, raise, pragma Assert
    • 

  • Prozeduren, Funktionen, Parametermodi in / out / in out, benannte Parameter und Vorgabewerte, Überladung von Unterprogrammen und Operatoren, Rekursion, Umbenennung (renames)
    • 

  • Ada 2012: Verträge with Pre => …, Post => … mit X'Old und F'Result (Verletzung: Ada.Assertions.Assertion_Error), Ausdrucksfunktionen function F … is (Ausdruck);
    • 



Pakete, Generics, Ausnahmen

    

  • Paketspezifikation und -rumpf, privater Teil, Initialisierungsteil, verschachtelte Pakete, Kindpakete (package Eltern.Kind), with, use, use type
    • 

  • generische Pakete und Unterprogramme; formale Typen private, limited private, (<>), range <>, mod <>, digits <>, delta <>, Feld- und access-Typen; formale Objekte (in, in out); formale Unterprogramme mit is <>
    • 

  • vordefinierte und eigene Ausnahmen, raise E with "Text", raise;, Behandler mit when E : others =>, Ada.Exceptions (Exception_Name, Exception_Message)
    • 



Tasking

    

  • Tasks und Task-Typen (mit Diskriminanten), Felder von Tasks, Tasks über access-Typen
    • 

  • Entries mit Parametern, accept … do … end, Rendezvous, verschachtelte Rendezvous
    • 

  • select mit Wächtern (when), or delay, or terminate, else; zeitbegrenzte und bedingte Entry-Aufrufe
    • 

  • delay und delay until mit simulierter Uhr (Ada.Calendar.Clock), abort, E'Count, T'Terminated, T'Callable
    • 

  • geschützte Objekte und Typen (Ada 95): Funktionen, Prozeduren, Entries mit Barrieren
    • 

  • Erkennung von Verklemmungen: können alle Tasks nicht mehr weiter, wird das Programm mit einer Zustandsliste beendet
    • 



Bibliothek

    

  • Ada.Text_IO (auch unter dem Ada-83-Namen Text_IO): Put, Put_Line, New_Line, Get, Get_Line (Prozedur und Funktion), Skip_Line, End_Of_File, End_Of_Line, Set_Col, Col; generisch Integer_IO, Modular_IO, Float_IO, Fixed_IO, Enumeration_IO
    • 

  • Ada.Integer_Text_IO, Ada.Float_Text_IO, Ada.Calendar (Time, Clock, Seconds, + / − / Vergleiche), Ada.Numerics (Pi, e), Ada.Numerics.Elementary_Functions (für Float), Ada.Numerics.Float_Random (deterministisch), Ada.Exceptions, Ada.Assertions, Ada.Unchecked_Deallocation
    • 




Abweichungen vom Standard


Nicht unterstützt

    

  • goto, Entry-Familien, requeue, Prioritäten, Darstellungsklauseln (for … use), 'Size, 'Address, 'Access, Zugriffe auf Unterprogramme, anonyme access-Typen, separate, generische Paketparameter
    • 

  • Dateien in Text_IO (nur Standard-Ein-/Ausgabe), Ada.Strings.*, Wide_Character, Ada-2005/2012-Merkmale außer den oben genannten (z. B. keine Interfaces, keine bedingten Ausdrücke, keine Container)
    • 



Abweichende Semantik

    

  • Laufzeitprüfungen sind immer aktiv; pragma Suppress wird ignoriert.
    • 

  • Division durch null und Überlauf lösen Constraint_Error aus (Ada 95). Ada 83 sah dafür Numeric_Error vor – hier ein Synonym für Constraint_Error.
    • 

  • Gleitkomma rechnet intern mit 64 Bit; Überlauf ergibt immer Constraint_Error.
    • 

  • Festkommawerte werden auf Vielfache von 'Small gerundet (Small = größte Zweierpotenz ≤ delta, wie in Ada 83).
    • 

  • Lesen einer skalaren Variablen ohne Wert löst Program_Error aus (in Ada ein „beschränkter Fehler“ mit undefiniertem Wert).
    • 

  • out-Parameter dürfen gelesen werden (Ada 95). Skalare Parameter werden kopiert, zusammengesetzte ebenfalls (Ada erlaubt beides).
    • 

  • Generische Rümpfe werden schon bei ihrer Deklaration geprüft; Fehler, die nur in einer Instanz auftreten, werden mit Instanzhinweis gemeldet.
    • 

  • Tasking: ein simulierter Prozessor mit deterministischem Round-Robin. delay stellt die simulierte Uhr erst vor, wenn kein Task mehr rechenbereit ist – Rechnen kostet also keine Zeit. Geschützte Funktionen laufen exklusiv statt parallel.
    • 

  • Eine unbehandelte Ausnahme in einem Task beendet den Task (wie in Ada), wird hier aber gemeldet. Eine unbehandelte Ausnahme im Hauptprogramm beendet sofort alle Tasks.
    • 

  • Verklemmungen werden erkannt und beenden das Programm – ein echtes Ada-Programm würde hängen bleiben.
    •

Tasking-Muster

task Puffer is
   entry Ablegen (X : in Integer);
end Puffer;

task body Puffer is
begin
   loop
      select
         when Platz =>
            accept Ablegen (X : in Integer) do
               ...
            end Ablegen;
      or
         delay 1.0;      -- Zeitüberschreitung
      or
         terminate;      -- (nicht zusammen mit delay)
      end select;
   end loop;
end Puffer;
