FlipJump Simulator

Ein einziger Befehl F;J: Bit Nummer F im Speicher flippen, danach nach Adresse J springen. Ein Befehl belegt 2·w Bit (erst F, dann J, jeweils w Bit, niedrigstes Bit zuerst). Start bei Adresse 0. Semantik nach der Spezifikation von Tom Herman (tomhea/flipjump). Zum Artikel: FlipJump auf itzwieseltal.wordpress.com

Ausdrücke: + - * / % ** << >> & | ^ ~ ! < > <= >= == != && || ?:, Bitbreite #x, Zahlen dezimal, 0x…, 0b…, Zeichen 'A', '\n'. Kommentare mit //.
Ein-/Ausgabe wie im Original: Flip von Adresse 2w gibt eine 0 aus, Flip von 2w+1 eine 1 (Zeichen niedrigstes Bit zuerst). Das nächste Eingabebit steht an Adresse 3w+#w, es wird jedes Mal neu geladen, wenn ein Befehl ausgeführt wird, der diese Adresse enthält. Ende: Selbstschleife (Sprung auf sich selbst, ohne sich selbst zu flippen). Ein Sprung unter 2w ist ein Fehler.
