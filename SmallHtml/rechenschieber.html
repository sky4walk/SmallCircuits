Mathematischer Hintergrund

✕ Multiplikation — C/D-Skala

Beide Skalen sind logarithmisch eingeteilt. Die Position von Wert x liegt bei:

x → log₁₀(x) × L

Verschiebt man die Zunge (C-Skala) um log₁₀(a), addiert man Logarithmen:

log(a) + log(b) = log(a·b)

Der Cursor zeigt auf der D-Skala direkt das Produkt ab.

÷ Division — CI/D-Skala

Die CI-Skala (C-inverted) läuft rückwärts — von rechts nach links. Damit entspricht die Verschiebung einem Subtrahieren des Logarithmus:

log(a) - log(b) = log(a/b)

Rechten Index («1») der CI-Skala über a auf der D-Skala stellen, Läufer auf b der CI-Skala — das Ergebnis a/b steht darunter auf D.

+ Addition — L-Skala

Die L-Skala ist linear (0 bis 1). Hier findet keine logarithmische Transformation statt:

Position(x) = x × L

Zunge um den Wert a verschieben, Läufer auf b der Zunge — die rote Linie zeigt auf der festen Skala direkt a + b.

Hinweis: Auf echten Rechenschiebern ist die L-Skala die Mantissen-Skala (log₁₀ linear abgetragen). Hier dient sie als einfaches Modell für das Addieren von Längen.

− Subtraktion — LI-Skala

Die LI-Skala (L-inverted) ist eine gespiegelte lineare Skala — analog zur CI-Skala, aber ohne Logarithmus:

Position(x) = (1 − x) × L

Rechten Index («0») der LI-Skala über a stellen, Läufer auf b der LI-Skala — damit wird b von a subtrahiert:

a − b = a + (−b)

Der Cursor zeigt auf der L-Skala das Ergebnis a − b.

Warum funktioniert das? Der Rechenschieber macht aus Multiplikation eine Addition durch die Eigenschaft des Logarithmus: log(a·b) = log(a) + log(b). Den Logarithmus physisch als Länge darzustellen und dann Längen zusammenzufügen — das ist das geniale Prinzip, das William Oughtred um 1622 mit zwei gegeneinander geführten logarithmischen Skalen umsetzte. Die Bauform mit Zunge im festen Körper kam in den 1650er-Jahren hinzu. Vor dem Taschenrechner waren Rechenschieber das wichtigste Werkzeug von Ingenieuren, Wissenschaftlern und Piloten. Ein geübter Benutzer konnte damit in Sekunden auf 3 Stellen genau rechnen.
