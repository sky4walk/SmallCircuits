Betriebssystem-ROM

Der Ace braucht sein 8-KB-ROM mit dem Forth-System. Lade es als eine Datei (8192 Bytes, z. B. ace.rom) oder als die beiden Hälften rom-a.z1 + rom-b.z2 (je 4096 Bytes, gemeinsam auswählen).

Noch kein ROM geladen.

ROM-Satz

Erweiterungs-ROM (F000–FFFF)

Optionales 4-KB-ROM ganz oben im Speicher, z. B. das DOS des Deep-Thought-Diskinterfaces (AceDos.rom). Es braucht das dazu gepatchte System-ROM (acebootrom.rom), das nach dem RAM-Test nach F815 springt. Ein Laufwerk ist noch nicht emuliert: Die DOS-Wörter sind da, Diskettenzugriffe wie CAT warten aber endlos – dann Reset.

Kein Erweiterungs-ROM.

Prüfsummen

Erwartet (CRC32): dc8438a5 (untere 4K) und 4009f636 (obere 4K). Abweichende ROMs werden trotzdem gestartet.

Schnellstart

Nach dem Start erscheint unten der Cursor. Probier 2 3 + . und Enter, oder VLIST für alle Forth-Wörter. Die PC-Tastatur ist direkt aktiv, sobald du ins Bild klickst.

Programmbibliothek

Ein Klick auf „Laden & starten“ macht einen Kaltstart, legt das Band ein, tippt die LOAD-Befehle und das Startwort. Das Band läuft dabei automatisch.

Band abspielen (.tap, .tzx, .wav)

  • Kein Band eingelegt.

Mit Bandautomatik startet das Band von selbst, sobald das ROM liest, und stoppt nach jedem Datenblock – auch Spiele, die später weitere Abschnitte nachladen, laufen so ohne Handgriff. Ein Klick auf einen Block spult dorthin. Der Ace braucht beim Laden den Dateinamen, z. B. LOAD name (Wörterbuch) oder 0 0 BLOAD name (Bytes).

Aufnahme (SAVE / BSAVE)

Alles, was der Ace mit SAVE name oder BSAVE ausgibt, wird mitgeschnitten und dekodiert.

  • Noch nichts aufgenommen.

Schnappschüsse (.ace)

Das verbreitete Format der Ace-Emulatoren (xAce, EightyOne): Speicher 2000–7FFF samt Registern. Braucht mindestens 19 KB, wird beim Laden automatisch eingestellt.

Gesamtzustand

Sichert CPU, gesamten Speicher, RAM-Ausbau und ROM in eine Datei. Ohne Browser-Speicher, alles bleibt bei dir.

Text eintippen

Forth-Quelltext hier einfügen; die Werkbank tippt ihn Zeichen für Zeichen auf der Ace-Tastatur. Jede Zeile wird mit Enter abgeschlossen.

Bildschirmtext

Soundbox (AY-3-8910)

Dreistimmiger Tongenerator mit Rauschen und Hüllkurve, 3,25 MHz. Valkyr nutzt ihn, wenn man im Optionsmenü „(S) Soundbox“ wählt. Aus Forth: 7 253 OUT 56 255 OUT wählt Register 7 und schreibt den Wert.

Joystick (Port 01)

Boldfield-Joystick: Bit 0 hoch, 1 runter, 2 rechts, 3 links, 5 Feuer. Valkyr, Frogger und Cygnus fragen ihn ab. Mit Pfeiltasten-Joystick wirken die Pfeiltasten nicht mehr als Ace-Cursortasten.

ETI-Farbkarte (1984)

Selbstbauprojekt aus Electronics Today International, April 1984: 8 Farben für Vorder- und Hintergrund je Zeichen. Ein Latch bei 2700h hält die aktuelle Farbe (Bit 0–2 Vordergrund, 4–6 Hintergrund, Bit 7 = übernehmen); jeder Schreibzugriff auf den Bildspeicher kopiert sie in den Attributspeicher. Einschaltfarbe grün auf schwarz.

Video-Timing

Zugriffe auf 2400–27FF/2C00–2FFF während des Bildaufbaus lassen die CPU warten. Zugriffe auf die Spiegel 2000–23FF/2800–2BFF haben Vorrang vor dem Bild und erzeugen sichtbare Störpunkte.

ZX-Drucker (Port FB)

0 Zeilen

Protokoll wie beim Spectrum: Bit 7 schreiben = Nadel, Bit 2 = Motor aus; lesen Bit 0 = Encoder, Bit 7 = Zeilenanfang, Bit 6 = 0 (Drucker vorhanden). Ace-Druckertreiber geben ihre Ausgabe hier aus.

Deep-Thought-Diskettenlaufwerk

  • Keine Diskette.

Das Interface von Deep Thought hat keinen Floppy-Controller: Ein 6850-UART schreibt die Bytes direkt als serielle Bitfolge (4 µs pro Bit, ungerade Parität) auf die Diskette, ein 6821-PIA steuert Motor, Kopfschritt und liest das Indexloch. Eine Spur hält genau einen Block. Abbilder im .DTI-Format von Simon Owen, kompatibel zu echten Diskettenauszügen. Befehle: FORMAT CAT DSAVE name DLOAD name DBSAVE DBLOAD DELETE DRIVE.

Speicher

Der Jupiter Ace

Gebaut 1982 von Jupiter Cantab in Cambridge, entwickelt von Richard Altwasser und Steven Vickers, die zuvor bei Sinclair am ZX81 und ZX Spectrum gearbeitet hatten. Statt BASIC startet der Ace direkt in Forth: schnell, sparsam und mit dem Komfort, kompilierte Wörter per LIST und EDIT wieder als Quelltext zu bearbeiten. Gegen Spectrum und C64 hatte er kommerziell keine Chance; es wurden nur einige tausend Geräte verkauft.
