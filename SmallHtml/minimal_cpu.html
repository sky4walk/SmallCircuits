Die Minimal-CPU


Akkumulator-Maschine mit 4 Bit Datenbreite, Harvard-Architektur (Programm im ROM, 16 Worte à 8 Bit) und Ein-Takt-Ausführung: Bei jeder steigenden Taktflanke wird genau ein Befehl komplett ausgeführt. Register: Programmzähler PC, Akku A, Ausgaberegister, Flags C und Z. Reset setzt alles auf 0.




CodeBefehlWirkungFlags


0nNOPnichts tun–


1nLDA nA ← n–


2nADD nA ← A + nC, Z


3nSUB nA ← A − n (als A + ¬n + 1)C, Z


4nOUTAUSGABE ← A (n egal)–


5nJMP nspringe zu n–


6nJC nspringe zu n, wenn C = 1–


7nJZ nspringe zu n, wenn Z = 1–




Bit 7 wird nicht ausgewertet, die Codes 8x–Fx verhalten sich wie 0x–7x. Beim Subtrahieren bedeutet C = 1 „kein Borgen“ (A ≥ n), wie bei ARM und 6502. Das Steuerwerk ist festverdrahtet:


LD_A = D1 + D2 + D3     NA = D1     SUB = D3     LD_F = D2 + D3
LD_OUT = D4             JMP = D5 + D6·C + D7·Z



Simulator


    

  • Takt ▶ führt einen Befehl aus (eine steigende Flanke), ◀ Zurück nimmt Takte zurück, Start läuft mit dem eingestellten Tempo.
    • 

  • Im Datenpfad zeigen grüne Leitungen, welche Wege im aktuellen Takt etwas bewirken; orange Werte mit „→“ werden bei der nächsten Flanke übernommen.
    • 

  • Ein Sprung auf sich selbst wird als HALT erkannt und hält den Lauf an. Haltepunkte setzt man mit dem Punkt vor der Adresse.
    • 

  • Das Hex-Feld nimmt das ROM im selben Format wie das ROM-Bauteil von logisim_web: Hex-Bytes, durch Leerzeichen getrennt.
    • 

  • Tasten (im Simulator-Reiter): Leertaste/→ Takt, ← zurück, Eingabe Start/Stopp, R Reset.
    • 




Assembler


; Kommentar  (auch // Kommentar)
START   EQU 9          ; Konstante (auch: START = 9  oder  .equ START, 9)
        ORG 0          ; Adresse festlegen
        LDA START      ; Operanden: 9, 0x9, 0b1001, 9h, $9, auch #9
loop:   OUT
        SUB 1
        JZ  fertig     ; Sprungmarken
        JMP loop
fertig: OUT
        JMP $          ; $ = Adresse des Befehls selbst
        DB  0x00, 12   ; Rohbytes


Pseudobefehle: HALT/HLT = JMP auf sich selbst, INC [n] = ADD 1, DEC [n] = SUB 1, CLR = LDA 0, TST = ADD 0 (setzt Z passend zu A, löscht C). Operanden dürfen einfache Ausdrücke sein (loop+1, START*2-3). Groß-/Kleinschreibung spielt keine Rolle.

Hinweise: Am Programmende erzeugt der Compiler eine Endlosschleife (Halt). carry und zero beziehen sich auf die letzte Rechnung; ein Vergleich rechnet selbst und verändert die Flags. Ein Vergleich mit 0 fügt ein ADD 0 ein, wenn das Z-Flag nicht schon zu A passt – das löscht dabei C. Der Optimierer entfernt Sprünge auf den nächsten Befehl, leitet Sprungketten um und streicht toten Code.
